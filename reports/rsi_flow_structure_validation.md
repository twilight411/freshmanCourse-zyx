# rsi-flow 结构验证补充报告

整理人：朱雅轩。验证日期：北京时间 2026-11-17。

## 问题与处理

原项目下载 `cc.eamon.open:auto-config:1.0.6` 时，`central.horsecoder.com:8081` 返回 401。用户随后提供课程的 Maven `settings.xml`；使用其中与仓库 ID `releases` 匹配的账号配置后，原版 `auto-config:1.0.6`、`easyfile:0.0.3`、`scheduler-core:0.1.2` 的 POM 请求均返回 200，独立缓存下的正式构建也成功。

正式代码保留原版依赖、外部模型配置类型以及两个定时 Holder。认证配置保存在仓库外，通过命令参数指定，没有上传课程账号。此前已完成的公开依赖改造作为独立备选补丁保留，不混入正式方案；其功能范围和验证证据单列。

同时更新测试插件以适配 Java 17。Windows 中文路径下 JaCoCo agent 在独立缓存中启动失败，因此默认不插入覆盖率 agent，所有测试仍正常执行；覆盖率统计可通过 `-Pcoverage` 单独开启，本轮未验证该选项，也不报告代码覆盖率。根项目打包还发现 Spring Boot 接入模块缺少 `spring-boot` 编译依赖，现已补齐。补丁和逐项说明见 [rsi-flow 材料目录](../experiments/rsi-flow/README.md)。

## 实际执行结果

已在原版依赖下运行 **20 项 Java 测试，0 失败、0 错误、0 跳过**。其中包括 11 项真实 `FlowEngine` 结构用例、3 项原版依赖检查、6 项上游回归用例。离线图检查及其 **8 项正反例测试**通过。八模块根项目另完成打包检查，打包阶段不重复执行测试。

| 检查 | 输入或条件 | 已验证行为 |
|---|---|---|
| 顺序与短分支 | 11 字符输入 | ROUTE → SHORT → VERIFY，返回目标行 |
| 长分支与嵌套 | 超过 130,000 字符 | ROUTE → CHUNK → DRAFT → VERIFY，返回目标行 |
| 阈值边界 | 4096 与 4097 字符 | 分别进入短路径和检索子流程 |
| 跨块证据 | 关键词从第一个块末尾开始 | 关键词未被截断漏检，保留原文目标行 |
| 无证据 | 长、短两种输入 | 输出 `NOT_FOUND` |
| 有界传递 | 大量匹配行 | 传递证据不超过 4096 字符，包含换行 |
| 超长单行 | 匹配行本身超预算 | 不把超预算行传给下游 |
| 子流程 | 直接运行 `FLOW_AGENT_RETRIEVE` | CHUNK → DRAFT 并返回结果 |
| 上下文释放 | 先命中，再用新输入无命中 | 后一次不复用前一次证据 |
| 原版依赖加载 | 模型配置、调度类、文件工具 | 原依赖可实例化/加载，UTF-8 文件可读取 |

正式方案使用外部课程配置及独立缓存做干净构建，证据入口为 [原版依赖验证索引](../experiments/rsi-flow/latest-authenticated.json)。每次运行的 `summary.json` 标记 `mode`、`status`、北京时间起止、测试数、真实路径及日志 SHA-256；以 `mode=authenticated` 且 `status=passed` 的记录为正式方案证据。无私服方案的 `runs/20261117_221118/` 只代表备选路径。

本轮测试还暴露并修复了原占位检索器的两个边界问题：关键词跨块漏检，以及证据预算未计入换行。这些修复均有引擎内用例覆盖。

## 结论与限制

现阶段可以确认原版依赖下载与全模块编译打包，以及普通流程的顺序、条件分支、嵌套子流程、长输入和有界证据传递。该示例仍采用字符串匹配和证据转发，不调用模型，因此不代表完成复杂语义 Agent 或提升 Text-to-SQL 准确率。定时类可加载，但定时/分布式调度服务、远程 HTTP 服务和跨操作系统运行不在本次验证范围。测试未自动加载定时样例，避免启动未配置的后台服务。

下一步应保持数据、模型和预算一致，将节点替换为实际 Text-to-SQL 组件，并与已有直接提示基线独立比较；已有 BIRD 成绩不随本轮结构验证改变。

## 复现

```bash
python scripts/run_rsi_flow_validation.py --settings "本机课程配置文件/settings.xml"
```

需要 Git、Python 3.10+、JDK、Maven 和合法可用的课程配置。已验证环境为 Windows、JDK 17、Maven 3.8.9。复现会下载依赖，不会调用付费模型或下载基准数据库。没有私服配置时，可用 `--portable` 验证单列的备选方案。
